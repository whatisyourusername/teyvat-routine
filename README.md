# Teyvat Routine

원신 Windows PC 버전의 반복 작업을 화면 인식과 키보드·마우스 입력 녹화로 수행하는 WPF 프로그램입니다.

현재 버전은 **v0.15.2**입니다. 소스, 실행 파일, 실제 사용 중인 녹화와 인식 설정을 함께 보관한 스냅샷입니다. 현재 파티와 FHD 화면에서 조정했으며 다른 파티·해상도에서는 별도 등록과 검증이 필요합니다.

## 실행

1. 저장소 전체를 내려받거나 복제합니다.
2. Windows x64와 **.NET 6 Desktop Runtime x64**가 설치된 환경에서 `portable/TeyvatRoutine.exe`를 실행합니다. EXE뿐 아니라 같은 폴더의 DLL·JSON·`data` 폴더도 필요합니다.
3. 원신은 사용자가 직접 실행하고 계정 인증을 마칩니다. 게임과 프로그램의 실행 권한을 맞춥니다. 현재 검증 환경에서는 둘 다 관리자 권한으로 실행했습니다.
4. 게임 창과 실제 렌더링 해상도를 선택하고, 왼쪽에서 실행할 작업과 전투 횟수를 지정합니다.
5. 실행 중에는 원신을 앞쪽 창으로 유지합니다. 즉시 중단은 **Ctrl+Alt+End**입니다.

상세 설정과 녹화 방법은 [사용법](docs/사용법.txt)을 참고하세요. 프로그램을 켜는 것만으로 루틴이 시작되지는 않습니다.

## 주요 기능

- 작업별 실행 여부와 비경 전투 횟수 선택
- 시작·완료 화면 확인, 재생 중 완료 감지 시 남은 입력 생략
- 메뉴 좌표 입력과 3D 카메라 상대 이동 녹화
- F1~F12와 Esc 입력 녹화, Alt+Tab 후 버튼으로 녹화 저장
- 나무 이미지 탐색, 좌우·상하 시점 보정, 도착 F 표시 확인
- 전투 완료까지 사이클 반복, 현재 파티의 두 번째 E 발동 및 4번 교체 확인
- 로그인 문·로딩·비경 입장 안내를 확인하며 대기
- 자동·수동 중간 재개와 해상도별 프로필

## 저장소 구성

```text
src/TeyvatRoutine/        C# WPF 소스와 자체 테스트
portable/                현재 실행 파일
portable/data/           현재 녹화·설정·잘라낸 인식 이미지
portable/data/profiles/  해상도별 프로필
scripts/build.ps1        소스 빌드와 자체 테스트
docs/                    사용법, 검증 이력, 참고 조사
```

프로필의 인식 이미지는 JSON의 `PngBase64` 값에 포함됩니다. 현재 FHD 프로필과 UHD 프로필을 보존하며 UHD 프로필은 미등록 상태입니다. 실행 로그, 전체 화면 진단 캡처, 과거 백업, 빌드 캐시는 포함하지 않습니다.

`portable/data`는 버전 관리되는 현재 설정 스냅샷입니다. 프로그램이 이 경로의 설정을 저장하면 Git 변경 사항으로 표시됩니다. 프로필을 교체하거나 Git으로 복원하기 전에는 프로그램을 종료하고 필요한 녹화를 백업하세요.

## 소스 빌드 및 테스트

Windows와 **.NET 6 SDK**가 필요합니다. 외부 NuGet 패키지는 사용하지 않으며 프로젝트의 `NuGet.Config`는 패키지 소스를 비웁니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

출력은 `artifacts/TeyvatRoutine/`, 테스트 결과는 `artifacts/self-test.txt`입니다. 자체 테스트는 실제 게임에 입력을 보내지 않습니다. 현재 `portable/`와 기존 사용 중인 프로그램을 덮어쓰지 않습니다.

## 검증 상태와 남은 작업

- v0.15.2 자체 테스트 173개 통과.
- 실제 전투·보상 3회 반복과 4번 교체 재시도 확인.
- 2026-10-21 몬드 이동 → 합성 → 새로 녹화한 일일 보상 단계 완료 판정 및 사용자 정상 동작 확인.
- 일일 초기화 뒤 실제 보상을 받을 수 있는 상태의 전체 최종 테스트는 예정되어 있습니다.
- 시간대별 로그인 문과 공월 팝업은 추가 등록·검증이 필요합니다.
- 이동 및 일부 메뉴 조작은 녹화에 의존합니다. 다른 캐릭터의 이동속도, 카메라 상태, 메뉴 상태가 달라지면 동선이 달라질 수 있습니다.
- 현재 파티용 스킬 확인을 다른 파티에 자동 학습하는 기능은 없습니다.

[현재 검증 상태](docs/STATUS.md)와 [개발 중 검증 이력](docs/검증기록.txt)을 참고하세요. 이력의 이전 버전 미검증 문구는 당시 상태입니다.

## 참고

MAA의 작업 흐름과 이미지 인식 접근을 참고했으며 MAA 코드나 DLL을 포함하지 않습니다. 조사 내용은 [참고 기록](docs/MAA-원신-조사결과.txt)에 있습니다.

원신 및 게임 내 이미지는 해당 권리자의 자산입니다. 이 프로젝트는 비공식 도구이며 게임 운영정책상 사용 허용을 보장하지 않습니다.
